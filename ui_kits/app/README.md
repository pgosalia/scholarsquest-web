# Scholar's Quest — Student & parent app UI kit

The signed-in product: where students join lessons, practice, and where parents read progress.
Lighter chrome than the marketing site (white app surface, cream only for empty space),
same pill/badge/teal-active vocabulary.

Screens (all in `index.html`, switched from the left rail):
- **Dashboard** — next lesson, streak, subject mastery, this week's assignments
- **Lesson room** — video call layout with whiteboard, tools rail and session notes
- **Practice** — a question set with answer choices, hint, and instant feedback
- **Progress** — the parent-facing report: score history, mastery by topic, tutor notes

Composed from the design-system components; nothing is re-implemented locally.

> Note: no production app was supplied, so these are built from the brand assets and the
> stated offering rather than recreated from source code.
